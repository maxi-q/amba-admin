## Структура

- Верхний stepper: `1 Настройка спринта` → `2 Вознаграждение` → `3 Задания`
- Справа: вторичная кнопка «Сохранить черновик»
- Форма: 700×550 px, border `#e4e4e4`, radius 8 px
- Строка «Название»: label 224 px + input 428×40 px
- Строка «Описание»: label + hint «Пару слов о спринте» + textarea 428×72 px
- Строка «Продолжительность»: label + календарь на два месяца
- Под формой справа: primary-кнопка «Продолжить»
