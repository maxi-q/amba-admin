## Layout и состояния

- Рабочая область спринта состоит из основного контента и правого сайдбара шириной 260 px.
- В проверке после вкладок показывается голубая плашка высотой 69 px: «Время на ответы вышло» и кнопка «Пропустить».
- Модалка пропуска имеет ширину 358 px, один красный action и текст о незавершивших задания участниках.
- В выдаче наград после вкладок показывается голубая плашка со счётчиком отправленных наград по участникам.
- Строка рейтинга содержит место, аватар, имя, статус выдачи, chips наград, XP и кнопку профиля.
- Профиль исполнителя имеет ширину 700 px и всегда относится к выбранному спринту. При выдаче наград внутри верхней карточки появляются chips наград и нижняя полоса подтверждения.
- В завершённом спринте по умолчанию открыты «Задания»; информационная плашка и поиск отсутствуют.
- По аннотации Figma в статусе проверки можно менять дату окончания спринта, но нельзя редактировать задания.

## Реализация

- Состояния спринта реализованы в `OpenSprintPage` и sprint-ветке `CompetitionLifecycle`; event-ветка оставлена без визуальных изменений.
- Переход в профиль доступен из рейтинга и из строки ответа задания. `taskId` в query сохраняет правильный экран возврата.
- Подтверждение в профиле отмечает отправленными все grant-ы участника существующим API по одному; после последнего участника спринт переводится в `completed`.
- Технические блоки ручного назначения и промокодных начислений удалены только из профиля спринта; API и event-профиль не изменены.
- В режиме проверки редактор спринта оставляет доступной только дату окончания, остальные поля disabled, этапы наград и заданий недоступны.
