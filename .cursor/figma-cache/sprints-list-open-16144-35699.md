## Сделано в коде

- Список: плоские строки (название, чип статуса, даты), шапка «Спринт» + «+ Добавить».
- Открытый спринт: `/rooms/:slug/sprints/:sprintId` — заголовок, pencil/trash, табы «Квесты» / «Таблица лидеров», правая панель.
- Редактирование: `/rooms/:slug/sprints/:sprintId/edit` (бывшая форма настроек).
- Legacy-вкладки SprintsHeader только на settings / info / leaderboard комнаты.

## Gap vs API / макет

1. Черновик — нет в API, чип «Черновик» не показываем.
2. Розовый бейдж «5» у названия / в сайдбаре — нет источника в API.
3. Описание спринта — нет в API → «Нет описания».
4. Квесты не привязаны к спринту (`sprintId`) — показываем задания комнаты.
5. Лидерборд API — только активный спринт комнаты; для других спринтов — заглушка.
6. Иконки календаря/карандаша/корзины — lucide (экспорт SVG с Figma нестабилен).
