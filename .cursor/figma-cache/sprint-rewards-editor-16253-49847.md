## Что изменилось

- Шаг 2 называется «Награды» и использует единую таблицу правил вместо отдельных режимов.
- В таблице объединены диапазоны мест и ручной отбор; доступны выбор строк, массовое удаление, редактирование и удаление правила.
- «Добавить место» открывает модальное окно с режимами «Одиночное / Диапазон / Ручной отбор» и каталогом наград.
- Справа закреплено превью распределения с вкладками «Как делятся / Все награды», поиском, XP и undo/redo.
- Пустое состояние и предупреждение о недостатке участников повторяют макет.

## Реализация

- `SprintCreationStepTwo.tsx` — таблица, модальное окно и превью.
- `SprintCreationHeader.tsx` — актуальное название шага.
- `sprints/slug/index.tsx` — одинаковый трёхшаговый экран для создания и редактирования спринта; сохранение синхронизирует правила и задания.

## API

- Поддерживаются `byRank`, `byPoints` и `manual` через текущие reward-rules endpoints.
- Настоящего draft-статуса у спринта всё ещё нет; «Сохранить черновик» остаётся UI-заглушкой.
