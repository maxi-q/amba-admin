## Реализация

- На списке добавлена кнопка «Добавить», компактные строки, статусы ответов, количество исполнителей, дедлайн и действия.
- Маршрут создания: `/rooms/:slug/creativetasks/private/new`; `?sprintId=:id` заранее выбирает спринт.
- Шаг 1: название, описание, спринт, ОРД-шаблон, файлы и запрашиваемые у исполнителя материалы.
- Шаг 2: дедлайн, выбор исполнителей и денежная награда; запуск создаёт задание и whitelist.
- Черновик формы сохраняется локально в браузере.

## Ограничения API

- В private-task DTO нет отдельного дедлайна — интерфейс использует дату окончания спринта.
- Награда задания представлена только `rewardInRubs`; произвольные награды каталога прикрепить нельзя.
- Нет серверного draft-статуса; локальный черновик не синхронизируется между браузерами.
- Список не отдаёт агрегаты ответов и исполнителей, поэтому они запрашиваются отдельно для каждой строки.
