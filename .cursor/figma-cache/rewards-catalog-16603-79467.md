## Реализация

- Список, пустое состояние, заголовок, preview-кнопка и строки высотой 64 px приведены к макету.
- «Добавить» открывает модальное окно с иконкой, названием, изображениями и типом деления.
- Поддержаны целая и дробная награды, включая точность дробной.
- Создание, редактирование, удаление и загрузка изображений используют существующие reward endpoints.
- Системная награда «Рубли» отображается без действий.

## Ограничения API

- В DTO отсутствует описание награды, поэтому поле из макета нельзя сохранить без изменения backend-контракта.
- Нет признаков `isSystem` / `isEditable`; системность «Рублей» временно определяется по имени.
