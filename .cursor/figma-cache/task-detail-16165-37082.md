## Backend limits

- Ambassador DTO has `username`, but no full name or avatar URL; production uses `Avatar` fallback.
- `defaultMediaIds` has IDs, but the current app hook has no preview URL; production shows file placeholders, mock uses Figma thumbnails.
- There is no task paused/frozen field; pause control is visual-only and does not invent persistence.

`get_design_context` on the section and both narrow frames plus high-quality screenshots is sufficient; repeat only if the design changes.
